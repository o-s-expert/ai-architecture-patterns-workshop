= AI Architecture Patterns Workshop
:toc:
:toclevels: 2

A hands-on workshop on integrating AI capabilities into enterprise applications with Enterprise Java, LangChain4j, and CDI.

== Workshop Website

https://o-s-expert.github.io/ai-architecture-patterns-workshop/[Open Workshop Website]

== Overview

The workshop (about 4 hours) explores key AI architecture patterns through five progressive labs that share a consistent scenario.

== Technology Stack

* Java 21 and Apache Maven
* CDI and MicroProfile
* LangChain4j
* Google Gemini
* MkDocs Material (documentation website)

== Laboratories

[cols="1,2,1,4"]
|===
|Lab |Title |Duration |Description

|1 |Hello World |20 min |Connect Enterprise Java to an LLM using CDI and LangChain4j.
|2 |Memory |25 min |Add conversational memory and session isolation.
|3 |Annotations |25 min |Use declarative AI services, prompts, and tools.
|4 |RAG |45 min |Retrieve business knowledge and ground responses.
|5 |Planning |45 min |Generate, validate, and execute a structured plan.
|===

NOTE: The Java lab implementations will be added under `src/main/java/`.

== Maven Project

The project is a single-module Maven build (`os.expert:ai-architecture-patterns-workshop`) that targets *Java 21* and runs on Java SE through CDI, without an application server.

* *LangChain4j* (AI Services, memory, structured outputs, tools, RAG) and the *Google Gemini* integration
* *CDI* with *Weld SE*, plus the LangChain4j CDI portable extension
* *MicroProfile Config* (SmallRye Config) configured in `src/main/resources/META-INF/microprofile-config.properties`
* A local embedding model and in-memory embedding store for the RAG lab, so no database is required

Each lab has its own package under `src/main/java/os/expert/`:

[cols="1,2"]
|===
|Package |Lab

|`os.expert.lab1` |Hello World
|`os.expert.lab2` |Conversational Memory
|`os.expert.lab3` |AI Services and Annotations
|`os.expert.lab4` |Retrieval-Augmented Generation
|`os.expert.lab5` |Planning Pattern
|===

WARNING: The Java exercises have not been implemented yet; the packages currently contain only `package-info.java` files.

=== Gemini API Key

Obtain a key from https://aistudio.google.com/api-keys[Google AI Studio] and expose it as an environment variable. Never commit it.

[source,bash]
----
export GEMINI_API_KEY="YOUR_API_KEY"
----

The Gemini model name is configurable through `gemini.model-name` in `microprofile-config.properties`.

=== Build

[source,bash]
----
mvn clean verify
----

== Documentation Development

[source,bash]
----
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-docs.txt
mkdocs serve
----

Validate the production build with:

[source,bash]
----
mkdocs build --strict
----

== Website Deployment

The workflow `.github/workflows/deploy-docs.yml` builds the site with `mkdocs build --strict` and publishes it to GitHub Pages using GitHub Actions on every push to `main`, or manually through `workflow_dispatch`. Generated output (`site/`) is not committed.
