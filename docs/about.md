# About

## About the Workshop

*Implementing AI Architecture Patterns with Enterprise Java* teaches experienced engineers how to integrate AI capabilities into enterprise applications using LangChain4j and CDI. Through five progressive labs, participants move from basic LLM integration to planning workflows while focusing on architectural trade-offs.

## Who Should Attend

- Java developers
- Software engineers
- Software architects
- Technical leaders
- Engineers building enterprise AI solutions
